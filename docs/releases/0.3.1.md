# DFragonCropper 0.3.1

Windows x64 portable 미리보기 릴리스입니다. 실행 파일과 `SHA256SUMS.txt`를 함께 제공합니다.

## 사용성 수정

- ROI를 드래그하는 도중 화면을 스크롤하거나 창 크기를 바꾸어도, 처음 누른 원본 픽셀 위치가 바뀌지 않습니다.
- 설정 파일의 손상이나 외부 변경 때문에 캡처가 차단되면 모든 탭에서 원인을 볼 수 있습니다. 오류 상태에서는 프로필과 설정 편집을 함께 차단하고 저장 전 입력은 유지합니다.

## 배포

- GitHub Actions에서 Windows용 검사와 portable 빌드를 자동 실행합니다.
- 버전 태그로 EXE와 SHA-256을 포함한 릴리스를 발행합니다.
- 프로그램의 용 아이콘은 실행 파일·창·트레이에 적용됩니다. 제품 소개, 캡처 개념도와 아키텍처는 README에서 확인할 수 있습니다.

## 업데이트 안내

0.3.0을 **Quit**로 종료한 뒤 새 EXE를 기존 설정과 캡처가 있는 폴더에 두세요. 설정 형식은 그대로 유지됩니다. 자세한 방법은 [배포 안내](https://github.com/blahaj94/dfragon-cropper/blob/v0.3.1/docs/distribution.md)에 있습니다.

주 모니터의 한 프레임에서 모든 ROI를 lossless PNG로 저장하는 캡처 방식은 변경하지 않았습니다. 코드서명, 자동 업데이트, 멀티모니터와 서버 업로드는 지원하지 않습니다.
