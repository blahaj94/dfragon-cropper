# DFragonCropper 0.4.0

Windows x64 portable 미리보기 릴리스입니다. 실행 파일과 `SHA256SUMS.txt`를 함께 제공합니다.

## ROI 편집

- **F12**로 주 모니터의 정지 화면을 테두리 없는 전체화면 선택창에 표시합니다. 마우스로 드래그하면 편집창으로 돌아오고 Esc는 선택을 취소합니다.
- 커서 오른쪽 아래에 픽셀 확대경을 표시해 작은 영역도 정확하게 지정할 수 있습니다. 화면 가장자리에서는 확대경이 안쪽으로 이동합니다.
- 그린 영역을 기존 ROI에 적용하는 `Edit drawn ROI`를 추가했습니다. 편집할 ROI를 먼저 선택하고 F12로 다시 그릴 수도 있습니다.
- 드래그와 숫자 입력은 같은 변경 초안을 편집합니다. 선택 결과 옆에 저장·취소 버튼과 변경 상태를 표시합니다. 저장하기 전에는 기존 좌표로 캡처하며 ROI ID는 유지됩니다.
- 프로필 사이를 오가며 새 영역을 그려도 각 프로필의 완료한 선택이 유지됩니다.

## 캡처 이력

- 원본·ROI 이미지에 화면 맞춤과 100% 보기를 추가했습니다. 큰 이미지는 가로·세로로 스크롤할 수 있습니다.
- 이미지를 빠르게 바꿨을 때 이전 이미지가 새 선택의 이름 아래에 표시되지 않도록 했습니다.

100%는 이미지 1픽셀을 CSS 1픽셀로 표시합니다. Windows 배율에 따라 화면에서 보이는 크기는 달라질 수 있으며 저장된 PNG는 변경하지 않습니다.

## 업데이트 안내

기존 앱을 **Quit**로 종료하고 새 EXE를 기존 설정·캡처가 있는 폴더에 두세요. 0.3.x의 설정 형식을 그대로 사용합니다. 자세한 방법은 [배포 안내](https://github.com/blahaj94/dfragon-cropper/blob/v0.4.0/docs/distribution.md)에 있습니다.

주 모니터 캡처·PNG 저장 방식은 유지하고 키 감지에 F12 선택 요청을 추가했습니다. 새 F12 선택창의 Windows 10 실기·100%/150% 검증은 아직 완료하지 않았습니다. 자동 검사와 과거 캡처 실기 결과를 새 기능의 실기 통과로 해석하지 않습니다. 코드서명, 자동 업데이트, 멀티모니터와 서버 업로드는 지원하지 않습니다.
