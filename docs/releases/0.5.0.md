# DFragonCropper 0.5.0

캡처해 모아 둔 ROI 이미지에 캐릭터 닉네임을 한 장씩 작성하는 **Ground Truth** 탭을 추가했습니다. Windows x64 portable 미리보기 릴리스이며, 실행 파일과 `SHA256SUMS.txt`를 함께 제공합니다.

## 이미지별 정답 작성

- 오래된 캡처부터 오른쪽 연속 목록에 표시하고, 아래로 스크롤하면 다음 캡처를 불러옵니다. 왼쪽 목차로 원하는 캡처 위치에 이동합니다.
- 이미지 옆에 닉네임을 입력하고 해당 행의 **Save**로 저장합니다. **Enter**는 저장에 성공한 뒤 다음 미작성 이미지로 이동하며, 한글 입력기 조합 중인 Enter는 저장하지 않습니다.
- **Hide images with answers**로 정답이 있는 이미지를 숨깁니다. **Show empty capture headings**로 필터 후 비어 있는 캡처의 제목과 목차를 남길지 선택합니다.
- 이미지 확대는 화면 표시만 바꿉니다. 작성 중인 입력은 스크롤·필터·탭 전환 중에도 유지되며, 저장에 실패하거나 저장 도중 다시 입력해도 최신 초안을 보존합니다. 앱을 종료하기 전에는 필요한 정답을 저장하세요.

## 저장과 데이터 보존

각 이미지의 정답은 해당 캡처의 `metadata.json` 안에 선택적 `groundTruth` 필드로 저장합니다. 빈 입력과 공백만 있는 입력은 `null`로 저장하고, 그 외 텍스트는 입력한 그대로 보존합니다. 완료 여부를 위한 별도 플래그는 저장하지 않습니다.

기존 metadata 필드와 모든 PNG 파일을 보존합니다. 정답 저장 전 직전 정상 metadata를 `metadata.json.bak`에 한 세대 보관하고 파일을 원자적으로 교체합니다. 외부 변경이나 지원하지 않는 데이터를 발견하면 덮어쓰기를 중단합니다. 자세한 사용법은 [이미지별 정답 작성](https://github.com/blahaj94/dfragon-cropper/blob/v0.5.0/docs/ground-truth.md)을 참고하세요.

## 업데이트 안내

기존 앱을 **Quit**로 완전히 종료하고 새 EXE를 기존 설정·캡처가 있는 **같은 폴더**에 두세요. `config.json`, `config.json.bak`, `captures/`와 이전 `.dev-captures/`가 있다면 보존합니다. 0.3.x·0.4.0의 설정 형식을 그대로 사용하며 이전 캡처에도 정답을 작성할 수 있습니다. [배포 안내](https://github.com/blahaj94/dfragon-cropper/blob/v0.5.0/docs/distribution.md)에 다운로드 확인과 교체 절차가 있습니다.

이번 변경은 정답 작성과 저장에 집중하며 기존 캡처·픽셀 처리 방식을 유지합니다. Windows CI의 자동 검사와 합성 프레임 UI 테스트는 실제 Windows 10의 PrintScreen·DPI·커서 제외 검증을 대신하지 않습니다. 0.4.0에서 추가한 F12 전체화면 선택·확대경의 Windows 10 실기 검증은 여전히 미완료입니다. 코드서명, 자동 업데이트, OCR과 서버 전송은 지원하지 않습니다.
