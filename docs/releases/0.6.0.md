# DFragonCropper 0.6.0

**캡처와 ROI 선택 단축키를 직접 바꿀 수 있습니다.** Windows x64 portable 미리보기 릴리스입니다.

`Settings` → `Keyboard shortcuts`에서 **Capture**와 **ROI selection**의 키·modifier를 고르고 **Save shortcuts**를 누르세요. 저장 직후 적용되며 재시작할 필요가 없습니다. 기본값은 PrintScreen과 F12이고, **Restore default shortcuts**로 되돌린 뒤 저장할 수 있습니다.

- F1~F24, PrintScreen, Pause, Scroll Lock, 문자·숫자와 Ctrl/Alt/Shift/Win 조합을 지원합니다. 문자·숫자는 Ctrl/Alt/Win 중 하나가 필요하며, Pause·Scroll Lock은 Ctrl 조합을 지원하지 않습니다.
- 현재 저장된 조합을 화면에 표시합니다. 저장 전 초안은 기존 단축키를 바꾸지 않으며 **Discard shortcut changes**로 취소할 수 있습니다.
- modifier가 정확히 일치할 때 한 번 실행합니다. 캡처 키는 다른 프로그램에도 전달하고, ROI 선택 키는 선택 전 화면이 바뀌지 않도록 앱에서 처리합니다. PrintScreen은 캡처에만 지정할 수 있습니다.

자세한 조합 제한과 동작은 [단축키 사용법](https://github.com/blahaj94/dfragon-cropper/blob/v0.6.0/docs/user-guide.md#단축키-바꾸기)을 참고하세요.

## 업데이트

기존 앱을 **Quit**로 완전히 종료한 뒤 새 EXE를 같은 폴더에 두세요. 설정·캡처 파일은 보존합니다. 유효한 이전 설정(v1/v2)은 프로필·ROI·기존 옵션을 유지하면서 v3로 이관하며, 원문을 `config.json.bak`에 보관합니다.

**0.5.0 이하 버전은 v3 설정을 읽지 못합니다.** 이전 버전으로 돌아갈 수 있도록 업데이트 전 설정 사본을 따로 보관하세요. 백업은 이후 저장으로 갱신됩니다. 복원은 앱을 종료한 상태에서 [설정 이관 안내](https://github.com/blahaj94/dfragon-cropper/blob/v0.6.0/docs/configuration.md#이전-설정-이관)를 따라 진행하세요.

캡처·ROI PNG 처리와 정답 저장 형식은 유지합니다. 단축키의 Windows 자동 검사는 합성 `SendInput`을 사용하며, Windows 10 물리 키보드·전체화면 ROI·DPI의 새 실기 검증을 뜻하지 않습니다. 코드서명과 자동 업데이트는 제공하지 않습니다.
