# 사용 가이드

[제품 소개](../README.md) · [문서 목록](README.md)

캡처 단축키(기본 **PrintScreen**) 또는 **Capture Now**로 기본 모니터(Primary Monitor)를 캡처합니다. 저장된 활성 프로필에 있는 ROI를 원본 물리 픽셀 그대로 잘라 PNG로 저장하며, 처음 실행하면 ROI 두 개를 가진 `Default` 프로필로 시작합니다.

## 프로필 선택과 저장

`Profiles` 탭의 `Edit profile`은 편집할 프로필을 선택합니다. 실제 캡처에 사용하는 활성 프로필과는 별도이며, `Use for captures`로 활성 프로필을 변경합니다.

- `Create profile`은 ROI가 없는 새 프로필을 만들고 바로 활성화합니다.
- `Create profile`, `Use for captures`, 프로필·ROI 삭제는 즉시 저장됩니다.
- 이름을 수정한 뒤 `Save name`, ROI 좌표를 수정한 뒤 해당 행의 `Save ROI`를 눌러 저장합니다. 새 숫자 영역은 `Add ROI`로 저장합니다.
- 저장 전 입력은 draft입니다. 편집 대상이나 탭을 바꾸고 캡처 상태가 갱신되어도 유지되며, `Discard changes`로 취소합니다. 캡처에는 저장된 활성 프로필만 사용합니다.

프로필 이름은 앞뒤 공백을 제거한 뒤 1~100자입니다. 프로필과 ROI의 ID는 생성 후 고정되며 삭제한 ID를 다시 사용하지 않습니다. 모든 프로필이나 ROI를 삭제할 수 있습니다. 활성 프로필을 삭제하면 다음 프로필, 마지막 항목이었다면 첫 번째 남은 프로필이 활성화됩니다. 남은 프로필이 없으면 활성 프로필도 없습니다.

활성 프로필이나 저장된 ROI가 없으면 **Capture Now**와 캡처 단축키에 의한 앱 캡처가 차단됩니다. Windows의 기본 PrintScreen 동작은 계속 전달됩니다.

## ROI 좌표와 이미지 드래그

ROI는 캡처할 사각형 영역입니다. 좌표는 Primary Monitor 왼쪽 위 `(0, 0)`을 기준으로 한 물리 픽셀입니다. `x`, `y`는 0 이상, `width`, `height`는 1 이상의 안전한 정수여야 합니다. 화면 배율에 따라 DIP로 환산해 입력하지 않습니다. 실제 화면 프레임을 벗어나는 ROI는 자동으로 줄이지 않고 오류로 처리합니다.

화면에서 영역을 지정하려면 다음 순서로 진행합니다.

1. `Profiles`에서 편집할 프로필을 선택합니다.
2. ROI 선택 단축키(기본 **F12**) 또는 `Select ROI` 버튼을 누릅니다. 버튼에는 저장된 단축키가 표시됩니다. 앱 창을 숨기고 주 모니터를 한 번 캡처한 뒤, 테두리 없는 전체화면 선택창에 정지 이미지를 표시합니다.
3. 마우스로 원하는 영역을 드래그합니다. 커서 오른쪽 아래 확대경과 픽셀 좌표를 보며 끝점을 맞춥니다. 화면 가장자리에서는 확대경이 안쪽으로 이동합니다.
4. 마우스를 놓으면 선택창이 닫히고 편집창에 좌표가 들어갑니다. `Add drawn ROI`로 새 ROI를 저장하거나 아래의 기존 ROI 편집 기능을 사용합니다.

**Esc** 또는 `Cancel selection`은 선택을 취소하며 기존 변경 초안은 유지합니다. 크기 없는 클릭은 저장하지 않고 다시 그릴 수 있게 합니다. 선택창이 보여 주는 화면은 실시간 영상이 아니므로 새로운 화면이 필요하면 Esc로 선택창을 닫고 ROI 선택 단축키를 다시 누르세요.

선택과 확대경은 동일한 한 정지 이미지를 사용합니다. 확대경은 화면에서만 픽셀을 확대해 보여 주며, 좌표는 원본 물리 픽셀 기준입니다. 캡처 PNG에는 확대경·선택 테두리를 넣거나 픽셀 크기를 바꾸지 않습니다.

Windows에서 앱의 키 감지가 활성화되어 있으면 저장한 ROI 선택 단축키로 다른 프로그램이나 트레이 상태에서도 선택을 요청할 수 있습니다. 선택이 완료되면 `Profiles`로 돌아옵니다. 선택 중에는 앱의 추가 캡처를 건너뛰고 Windows의 기본 PrintScreen 키 전달은 유지합니다.

### 기존 ROI의 영역 바꾸기

새 영역을 선택한 뒤 `Add drawn ROI` 아래의 `Replace existing ROI`에서 바꿀 기존 ROI를 선택하고 `Edit drawn ROI`를 누릅니다. 선택한 ROI의 숫자 좌표에 변경 초안이 들어가며, `Save ROI #N`을 눌러야 저장됩니다. 새 ROI를 만들지 않고 기존 ID를 유지합니다.

또는 `Preview target`에서 `ROI #N`을 먼저 선택하고 ROI 선택 단축키로 다시 그릴 수 있습니다. 드래그와 숫자 입력은 같은 변경 초안을 편집합니다. 잘못된 숫자는 오류로 표시하며 올바르게 수정하기 전에는 저장할 수 없습니다.

`Discard ROI #N changes`로 취소하면 저장된 좌표로 돌아갑니다. 저장 전에는 캡처에 기존 좌표를 사용합니다. 프로필이나 탭을 바꿔도 완료한 변경 초안과 프로필별 새 영역 선택은 유지됩니다.

## 캡처와 기록 열람

캡처가 시작되면 저장된 활성 프로필의 ID·이름·ROI 목록과 원본 저장 옵션을 고정합니다. 그 이벤트의 모든 ROI는 하나의 source frame에서 만들어집니다. 프로필 ID와 이름은 `metadata.json`에도 기록됩니다. 저장 중 추가 입력은 대기하지 않고 skipped로 집계됩니다.

`Captures` 탭에서 `Refresh history`를 누르면 최근 캡처 이벤트 최대 100개를 표시합니다. `Capture event`와 `Capture image`에서 저장된 원본 또는 ROI 이미지를 고르고 `Open capture folder`로 해당 폴더를 엽니다. `Open output folder`는 전체 캡처 저장 폴더를 엽니다.

캡처를 모아둔 뒤 이미지별로 캐릭터 닉네임을 입력하려면 `Ground Truth` 탭을 사용합니다. 오래된 캡처부터 연속으로 표시하고, 각 이미지의 정답을 해당 이벤트의 `metadata.json`에 저장합니다. 왼쪽 목차, 미작성 필터와 Enter 저장 동작은 [이미지별 정답 작성](ground-truth.md)에 정리했습니다. 0.5.0부터 사용할 수 있습니다.

이미지는 기본적으로 `Fit`으로 전체가 보이도록 표시됩니다. `100%`를 누르면 이미지 1픽셀을 CSS 1픽셀로 표시하고 큰 이미지를 가로·세로로 스크롤할 수 있습니다. 원본 이미지 크기도 함께 표시합니다. 다른 이미지를 선택하면 보기 배율은 유지하고 스크롤은 처음 위치로 돌아갑니다. 표시 방식은 저장된 PNG를 변경하지 않습니다.

목록의 100개 제한은 보관 기간이 아닙니다. 오래된 캡처를 자동으로 삭제하지 않으며, 프로필이나 설정을 변경해도 이미 저장한 파일은 유지됩니다. Portable 앱은 새 `captures/`와 이전 `.dev-captures/` 기록을 함께 읽습니다. 같은 이벤트 ID가 있으면 새 경로를 우선하며 기존 파일을 이동하거나 삭제하지 않습니다.

## 단축키 바꾸기

0.6.0부터 `Settings` → `Keyboard shortcuts`에서 **Capture**와 **ROI selection**의 키를 각각 고르고 Ctrl/Alt/Shift/Win을 조합할 수 있습니다. **Save shortcuts**를 눌러야 적용되며, 재시작할 필요는 없습니다. `In use`와 ROI 선택 버튼은 현재 저장된 조합을 표시합니다.

- **Discard shortcut changes**는 작성 중인 변경을 취소합니다. **Restore default shortcuts**는 PrintScreen/F12를 초안에 넣으므로 **Save shortcuts**로 확정하세요.
- F1~F24, PrintScreen, Pause, Scroll Lock, A~Z, 0~9를 지원합니다. 문자·숫자는 Ctrl/Alt/Win 중 하나와 함께 사용하세요. 두 동작의 조합이 같거나 Alt+F4·Win+L이면 저장할 수 없습니다. Pause·Scroll Lock에는 Ctrl을 조합할 수 없습니다.
- 선택한 modifier와 정확히 일치해야 동작합니다. 예를 들어 Ctrl+F8에는 Ctrl+Shift+F8이 반응하지 않습니다. 누른 채 유지해도 한 번만 실행합니다.
- 캡처 단축키는 다른 프로그램에도 전달됩니다. 해당 프로그램에서도 같은 키가 동작할 수 있으므로 겹치지 않는 조합을 고르세요. ROI 선택은 화면이 바뀌지 않도록 조합의 마지막 키 입력을 앱에서 처리합니다. Ctrl/Alt/Shift/Win 자체의 입력은 전달됩니다.
- PrintScreen은 캡처에만 지정할 수 있습니다. 다른 캡처 키로 바꿔도 Windows의 기본 PrintScreen 입력은 계속 전달됩니다.

### 게임에서만 단축키가 안 될 때

게임을 관리자 권한으로 실행했다면 DFragonCropper도 같은 권한으로 실행해 보세요.

1. DFragonCropper의 **Quit**로 완전히 종료합니다. **X는 기본적으로 트레이에 숨기므로 종료가 아닙니다.**
2. 사용하던 EXE를 우클릭하고 **관리자 권한으로 실행**을 선택합니다.
3. 게임창을 클릭한 뒤 저장한 캡처 단축키를 누릅니다.

일반 권한으로 실행한 게임에서는 앱도 일반 권한으로 사용하면 됩니다. 앱이 임의로 권한을 올리지는 않습니다. 같은 권한에서도 실패하면 앱의 오류·캡처 횟수와 EXE 옆 `logs/app.log`를 확인하세요. 게임의 입력 차단이나 전체화면 캡처 문제는 별도 확인이 필요합니다.

## 설정과 트레이 실행

`Settings`에서 옵션을 선택한 뒤 `Save settings`로 저장합니다. 저장 전에는 기존 설정을 사용하며, `Discard settings changes`로 취소할 수 있습니다. 설정 draft도 탭을 바꿔도 유지됩니다.

| 옵션                   | 기본값 | 동작                                                                                                                                 |
| ---------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| `Save original PNG`    | 켜짐   | 원본 PNG도 저장합니다. 끄면 이후 이벤트에는 ROI PNG와 metadata만 저장하며, ROI 생성에 필요한 한 프레임은 계속 메모리에서 캡처합니다. |
| `Close window to tray` | 켜짐   | 트레이를 사용할 수 있을 때 창의 닫기 버튼으로 백그라운드 실행을 유지합니다. 저장한 단축키 감지도 계속됩니다.                         |

`Hide to tray`로 창을 숨기고 트레이에서 다시 열 수 있습니다. 트레이 생성에 실패했거나 `Close window to tray`가 꺼져 있으면 창의 닫기 버튼은 앱을 종료합니다. macOS 개발 실행에서는 트레이 숨기기를 지원하지 않습니다.

완전히 종료하려면 창이나 트레이 메뉴의 `Quit`를 사용합니다. 진행 중인 PNG·설정 저장을 마친 뒤 종료합니다. 같은 사용자 데이터 폴더를 쓰는 앱을 다시 실행하면 기존 창을 복원해 설정 쓰기와 단축키 처리가 중복되지 않도록 합니다.

설정 오류나 백업 복구 방법은 [설정과 데이터](configuration.md), 새 버전으로 교체하는 방법은 [배포 안내](distribution.md)를 참조하세요.
